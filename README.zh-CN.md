# ClickLoop

基于 [mmmelson/SnapClick](https://github.com/mmmelson/SnapClick) 迭代的 macOS 原生鼠标连点器，使用 SwiftUI / AppKit，支持 macOS 13 及以上。

[English](README.md)

## 新增功能

- **更长时长**：解除 60 秒上限，可输入 600 秒、3600 秒等正数。
- **目标 CPS**：直接输入每秒点击次数，支持小数，最高 200。修改持续时间不会改变频率；旧预设按原“次数 / 时长”自动换算，保留实际频率。
- **无限连点**：打开“无限连点”，按目标 CPS 持续点击到停止，无需设置时长。
- **快捷键状态可见**：主窗口显示监听已就绪或缺少权限。系统授权后自动恢复监听，匹配的快捷键不会再传给前台应用。
- **独立计时**：连点由专用串行队列执行，运行期间避免 App Nap 降速，鼠标事件不会继承快捷键的修饰键。
- **连点状态图标**：执行连点时，系统菜单栏显示绿色点击图标和 **Clicking**；结束后恢复普通图标。
- **立即停止**：移动鼠标（含拖动）、再次按相同快捷键、按 Esc，或点击主窗口 / 菜单栏面板的“停止连点”。禁用方案、编辑方案和退出应用也会停止正在执行的连点。
- **启动图标动画**：主窗口图标短暂摆动，菜单栏图标短暂闪动；遵循系统“减少动态效果”设置。

有限模式立即执行第一次点击，后续间隔为“1 / 目标 CPS”；总次数为“目标 CPS × 持续时间”向上取整，包含持续时间内的每个计划点击。最高频率仍为 200 CPS。连点时保持鼠标停留在目标位置，实际频率受系统负载影响。

## 构建与使用

安装 Apple Xcode Command Line Tools 后运行：

```sh
git clone https://github.com/AndyJZhao/ClickLoop.git
cd ClickLoop
./Scripts/build_app.sh --launch
```

生成适配当前 Mac 架构的 `ClickLoop.app`，使用本地 ad-hoc 签名，可复制到“应用程序”。启用方案前，需在“系统设置 → 隐私与安全性 → 辅助功能”中授权 **ClickLoop**。默认预设均关闭，快捷键为 ⌥1（左键）和 ⌥2（右键）。

ClickLoop 使用独立应用标识 `com.andyjzhao.clickloop`，预设存放在 `~/Library/Application Support/ClickLoop/schemes.json`，不会修改 SnapClick 数据。如需迁移，退出 ClickLoop 后，将 SnapClick 的 `schemes.json` 复制到该目录；旧格式预设按有限模式加载。

若出现 SDK 与 Swift 编译器版本不匹配，可在构建 / 测试命令前设置 `SDKROOT=/path/to/compatible/MacOSX.sdk`，选择本机已有的兼容 SDK，无需修改全局工具链。

## 验证

```sh
./Scripts/test.sh
./Scripts/build_app.sh
```

自动检查覆盖长时长、非法输入、频率上限、有限次数完成、无限执行、立即停止、替换正在执行的方案和新旧预设存储兼容性。测试使用内存点击计数器，**不会发出鼠标事件**。

手动验证：授权辅助功能后，设置无限模式为每秒 10 次，在无害目标上按快捷键，检查菜单栏显示 **Clicking**，移动鼠标后立即停止并恢复普通图标；重新启动后分别检查 Esc 和相同快捷键能停止。另检查 600 秒能保存并在重新打开编辑器后保留。

`Tests/ClickTarget.html` 是独立的浏览器点击计数页。打开后，将鼠标放在蓝色区域，刷新页面清零，再触发“100 CPS / 1 秒”预设。预期接收 100 对按下/抬起事件、100 次点击、约 100 CPS，带修饰键的点击为 0。页面按最后一段连续点击计速，超过一秒的间隔会另起一段，避免前面的手动点击拉低平均值。2026-10-11 实体键盘验证中，Chrome 收到完整 100 次点击，实测 97.17 CPS，未携带快捷键修饰键；内部计时测试为 100.00 CPS。自动测试另覆盖主线程阻塞时的 100 CPS 计时、快捷键拦截、长按防重复、Esc 停止，以及有限 / 无限模式下移动和拖动鼠标立即停止。

本地 ad-hoc 构建在重新编译后签名会改变。即使系统辅助功能列表中的旧条目仍为开启，macOS 也可能要求移除并重新添加 ClickLoop。应用会显示实际授权和监听状态。
